# Horta no Apê: página de vendas

Página estática do guia **Horta no Apê** (R$ 22).

## Antes de anunciar
- **Checkout:** no fim do `index.html`, preencha `const CHECKOUT_URL = "";` com o link do checkout do Phoenix OS.
- **Pixel da Meta:** cole o código no `<head>`, no lugar marcado com `<!-- Cole aqui o código do Pixel da Meta -->`.

## Deploy
Projeto estático, sem build. Na Vercel: Framework Preset = Other, sem comando de build, diretório de saída = raiz.
